# Research Personal Preferences

## Session Logging (After Research Completion)

After completing research, log to session:
```
mcp__egregore-mcp__session_log_append(entries: "Research complete: {brief description}")
```

Example invocations:
```
[RESEARCH] Research complete: managed Postgres comparison - 3 options evaluated
[RESEARCH] Research delegated: API evaluation — 3 subagents launched
```
